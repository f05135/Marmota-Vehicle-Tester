# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `2.0.x` | Yes |
| `< 2.0.0` | No |

## Reporting a Vulnerability

If you discover a security issue in **Marmota Vehicle Tester**, please **do not** open a public issue. Instead, report it privately via GitHub Security Advisories (`Security` -> `Advisories` -> `Report a vulnerability`) on this repository.

Please include:
- A clear description of the issue and potential impact
- Steps to reproduce or proof of concept
- App version and operating system
